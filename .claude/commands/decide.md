---
description: 기술적 의사결정 지점에서 후보안 비교표를 만들고 ADR로 기록한다
---

지금 다뤄야 할 결정: $ARGUMENTS

1. 후보 2~4개를 표로 정리한다 (장점 / 단점 / 이 프로젝트 맥락에서의 적합도).
2. 추천안과 이유를 밝히되 단정하지 않는다.
   "이런 이유로 A를 권하지만, B도 다음과 같은 상황에선 타당하다" 식으로 균형 있게 서술한다.
3. 내가 선택하면 `/docs/decisions.md`에 다음 형식으로 append한다:

```
## [YYYY-MM-DD] [결정 제목]
- 후보: A, B, C
- 선택: B
- 이유: ...
- 감수한 단점: ...
- 재검토 조건: (이 결정을 다시 봐야 할 상황이 있다면)
```

4. 이미 비슷한 결정이 기록되어 있으면 중복 기록하지 말고 기존 항목을 참조하라고 알려준다.
